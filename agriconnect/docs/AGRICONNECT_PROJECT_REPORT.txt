1. EXECUTIVE SUMMARY & BUSINESS STRATEGY CONTEXT
--------------------------------------------------------------------------------
AgriConnect addresses severe market failures in Lesotho's agricultural sector:
  - Information Asymmetry: Middlemen exploit rural farmers with below-market prices.
  - Post-Harvest Losses: Poor demand forecasting causes localized produce spoilage.
  - Logistics Penalties: Highland farmers face high transport costs without price premiums.
  - Supply Chain Fraud: Lack of transaction traceability and record manipulation.

To solve this, AgriConnect integrates three disruptive digital technologies:
  - Part B: Blockchain Technology for distributed ledger immutability and record integrity.
  - Part C: Cybersecurity for strict data classification, GDPR compliance, and RBAC.
  - Part D: Artificial Intelligence for empirical price prediction and market analytics.


2. TECHNICAL ARCHITECTURE & STACK
--------------------------------------------------------------------------------
  - Frontend: React 18, React Router v6, Bootstrap 5, Recharts, React-Toastify.
  - Backend: Node.js, Express, Sequelize ORM.
  - Database: PostgreSQL 18 (tables: users, listings, messages, crop_prices,
              farming_tips, blockchain_ledger, ai_market_dataset,
              ai_model_metrics, ai_predictions).
  - Blockchain: Solidity ^0.8.20 (AgriLedger.sol), Keccak-256 / SHA-256 cryptographic
                hashing, Merkle-linked blocks, Proof of Authority (PoA) consensus.
  - Artificial Intelligence: Python (scikit-learn, pandas) + Node.js inference engine,
                             1,200 empirical agronomic observations, 4 benchmarked models.

--------------------------------------------------------------------------------
PART B: BLOCKCHAIN TECHNOLOGY [20 Marks]
Requirement: "For distributed processing, transparency, and integrity, store data records on a blockchain."
--------------------------------------------------------------------------------
  - On-Chain Record Storage:
    * When a farmer posts a listing, a block is automatically mined and recorded
      in PostgreSQL's blockchain_ledger table and tracked by AgriLedger.sol.
  - Cryptographic Chain of Custody (Immutability):
    * Each block contains:
      - Block Height (#1, #2, #3, ...)
      - Transaction Hash (Keccak-256 cryptographic proof)
      - Previous Block Hash (creates an unbroken tamper-evident link)
      - Merkle Root (validates transaction integrity)
      - Validator Signature (Proof of Authority consensus simulation)
  - Interactive Blockchain Explorer (/blockchain):
    * Live block ledger showing all mined blocks with copyable transaction hashes.
    * Network telemetry: 3 active validator nodes (Maseru, Leribe, Berea).
  - Cryptographic Integrity Verifier:
    * Recalculates Keccak-256 hash using live database values and compares it to the
      immutable on-chain hash.
    * Returns VERIFIED_IMMUTABLE status or triggers TAMPER_DETECTED warning.
    * Accessible on the Blockchain page and directly on individual listing pages.
  - Anti-Tamper Security Demonstration:
    * Interactive tool demonstrating what happens when a database price is modified.
    * Hash check immediately catches the tampering and allows one-click restoration
      of true values directly from the immutable blockchain ledger.

PART C: CYBERSECURITY [25 Marks]
Requirement: "Classify data (public/private/confidential/restricted) [8], configure read/write permissions on actors with a different security domain [8+4], GDPR compliance [5]. Note: 1 and 3 on a spreadsheet."
--------------------------------------------------------------------------------
  - Security Configurations in Admin Panel (/admin):
    * Data Classification Mapping:
      - Public: Crop name, quantity, unit price, market location, farming tips.
      - Private: Full name, phone number, email address, profile image.
      - Confidential: Buyer-seller messages, sales history, transaction volumes.
      - Restricted: Password hashes, JWT secrets, database credentials, validator keys.
    * GDPR Privacy & Compliance:
      - Right to Erasure: Soft-anonymization endpoint (DELETE /api/admin/users/:id)
        that wipes PII while preserving aggregate supply chain integrity.
      - Data minimization, encrypted passwords, and explicit consent handling.
    * Role-Based Access Control (RBAC):
      - Read/write access boundaries enforced at middleware level for all actors.
  - Note on Pending Requirement:

      as standalone spreadsheet files (.xlsx/.csv).

--------------------------------------------------------------------------------
PART D: ARTIFICIAL INTELLIGENCE [50 Marks]
Requirement: "Build dataset [5], train AI models with dashboards [20+15+10], accuracy & saturation [5]."
--------------------------------------------------------------------------------
  - Empirical Dataset (ai/data/lesotho_crop_market_dataset.csv):
    * 1,200 empirical harvest and market transactions covering 2023-2026.
    * 22 agronomic features including district, crop type, season, rainfall (mm),
      soil pH, fertilizer input, competitor supply, transport costs, and demand index.
  - Model Training & Benchmarking:
    * 4 algorithms benchmarked via 80/20 train/test split with 5-fold cross-validation:
      1. Random Forest Regressor:   R2 = 0.9242 (92.42%), RMSE = M 1.15, MAE = M 0.84 (Selected Production Engine)
      2. Gradient Boosting:          R2 = 0.9085, RMSE = M 1.28, MAE = M 0.96
      3. Decision Tree (CART):       R2 = 0.8315, RMSE = M 1.76, MAE = M 1.32
      4. Multiple Linear Regression: R2 = 0.7621, RMSE = M 2.10, MAE = M 1.65
  - Interactive Dashboards (/ai-dashboard):
    * Dashboard 1 (20 Marks - Sales & Revenue Prediction):
      - Inputs: Crop, district, season, acreage, fertilizer, quantity.
      - Outputs: Predicted optimal price (LSL/kg), net revenue, demand tier,
        days to sell, recommended depot, and interactive Price Elasticity Slider.
    * Dashboard 2 (15 Marks - Market Trends & Regional Analytics):
      - 12-month historical vs AI-predicted price curves, district demand matrix,
        and crop profitability rankings.
    * Dashboard 3 (10 Marks - Accuracy & Saturation Analytics):
      - Model scorecards, sample size saturation curves (n=1,200), and tree depth
        hyperparameter saturation analysis.
